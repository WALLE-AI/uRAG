# uRAG
能够直接应用任何领域生产系统的RAG
## Features
* 原子知识库建设，通过智能文本解析算法和chunk策略完成对私域各类非结构数据原子知识构建，形成领域原子知识库，包括多模态文本信息，比如图片信息
* 通过多路路由召回、混合检索、生成模型优化等策略，完成能够直接应用生成系统的RGA系统
* 支持主流RAG系统评测，包括白盒策略和黑盒测试
* 打造RAG系统benckmark能支持主流rag评测和领域评测
## BenckMark
* 支持主流的RAG评测方法，支持白盒策略和和黑盒测试
